# M1 人工聆聽驗收 — Pending

日期：2026-10-08。此表尚無人工聆聽結果；自動分析 waveform、非零輸出與資源
釋放不等於耳聽，不能將本表標成通過。本階段不修改 M0 作曲演算法。

## 操作

1. `npm run dev`，開啟本機網址；使用實際耳機或喇叭，先降低系統音量。
2. 每輪 Stop 後輸入表列 Seed，加入四件樂器再 Start。每個 Seed 實聽至少
   10 分鐘，使用牆鐘計時；暫停或無聲的排查時間不算入聆聽時間。
3. 0–2 分鐘：完整合奏，確認共同節拍、各聲部辨識、和聲與音量平衡。
4. 2–6 分鐘：依序 Solo Piano、Violin、Drums、Bass 各一分鐘，解除前一件 Solo。
   聽鋼琴力度／和弦尾音、小提琴持續音／換音、鼓組 Kick／Snare／Hi-hat、貝斯撥弦與止音。
5. 6–8 分鐘：解除 Solo，交替 Mute／Remove／加入，等待畫面標示的安全小節。
   檢查是否爆音、重複觸發、殘留長音或聲部失聯。
6. 8–10 分鐘：合奏，切到背景約 30 秒再回來。確認恢復共同拍點，沒有把
   錯過的音符一次補奏；若瀏覽器凍結分頁而有空白，記錄長度與恢復結果。
7. Stop，確認短淡出後無聲；再 Start 確認從相同 Seed 的第一小節重現。
   另於四個 `?instrument=<id>` Lab 逐件確認獨奏及載入取消／重試。
