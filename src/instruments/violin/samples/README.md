# Violin samples

M0 uses a **synth placeholder**, not recorded violin samples. No third-party audio is included.

This plugin owns its future sustained-note sample URLs and note mapping in `index.ts`. Before replacing `null`, verify source licenses and record each original/converted file in `docs/SAMPLE_LICENSES.md`. Pass the completed pitched `SampleBank` through the injected sample-voice factory; no other instrument is required. Long-note release and sample quality belong to M1 validation.
