# Electric Bass samples

M0 uses a **synth placeholder**, not recorded electric bass samples. No third-party audio is included.

This plugin owns its future sample URLs and note mapping in `index.ts`. Before replacing `null`, verify source licenses and record each original/converted file in `docs/SAMPLE_LICENSES.md`. Supply a pitched `SampleBank` to the injected sample-voice factory. No drum or other instrument is needed to generate or play this bass part.
